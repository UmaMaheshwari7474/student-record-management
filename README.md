# Student Record Management System

## Overview

Student Record Management System is a Java-based command-line application used to manage student records through a simple menu-driven interface.

## Features

* Add a new student
* View all student records
* Update student details
* Delete a student record
* Handle invalid student IDs
* Exit through a menu option

## Technologies Used

* Java
* ArrayList
* Object-Oriented Programming
* Encapsulation
* VS Code

## Concepts Practiced

### Classes

The project uses separate classes for student data, record management, and the main application.

### ArrayList

`ArrayList<Student>` is used to store multiple student objects dynamically.

### Encapsulation

Student fields are declared private and accessed through getters and setters.

### CRUD Operations

The application supports:

* Create - Add Student
* Read - View Students
* Update - Update Student
* Delete - Delete Student

## How to Run

Compile the Java files:

    "javac src\*.java"

Run the application:

java -cp src Main
